# Pass The Phone

Offline Egyptian Arabic party game v0.7.0+7. Verified toolchain: Flutter 3.47.7 / Dart 3.13.5. Dependencies are locked in pubspec.lock.

Run `flutter pub get`, `flutter analyze`, `flutter test`, and `flutter run`. Full Windows preflight: `powershell -ExecutionPolicy Bypass -File tool/release_preflight.ps1`.

Preflight builds unsigned release APK/AAB compilation checks. Normal release builds require owner-approved identity and private upload signing configuration. No key is generated by this repository or CI.
